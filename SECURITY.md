# Security

Picco works offline and only reads and writes the folders you add to it, but
it opens files from anywhere: photos, videos and `.picasa.ini` files. If a file
can make Picco crash, hang, or touch files it should not, that is a security
problem.

Please open an [issue](https://github.com/miamibc/picco/issues/new) that says
what kind of file and what goes wrong, but leave out the file itself and the
exact steps; we will agree in the issue on how to pass them on privately. You
will get an answer within a few days.

Only the latest release gets fixes.
