Небольшой локальный органайзер фотографий в духе Picasa 3. Написан на Rust
и egui, работает на Linux, Windows и macOS.

Pico читает и пишет файлы `.picasa.ini`, которые Picasa оставляла в папках с
фотографиями. Звёздочки, подписи, ключевые слова, повороты и правки, сделанные
в Picasa, видны в Pico и наоборот. Оригиналы фотографий Pico не меняет, пока
вы явно не нажмёте **Save**. В интернет ничего не отправляет.

## Готовые сборки

На странице релизов GitHub лежат архивы под все системы. Процессоры Intel и
AMD берут одни и те же сборки `x86_64` (64 бита) или `x86` (32 бита).

| Система | 64 бита | 32 бита | ARM |
|---|---|---|---|
| Linux (glibc 2.28+, 2019 г. и новее) | `pico-linux-x86_64` | `pico-linux-x86` | `pico-linux-arm64`, `pico-linux-armv7` (32-бит, Raspberry Pi) |
| Windows 10/11 | `pico-windows-x86_64` | `pico-windows-x86` | `pico-windows-arm64` |
| macOS 11+ | `pico-macos` — одна программа для Apple Silicon и Intel | — | — |

Сборка для macOS не подписана сертификатом Apple: при первом запуске
откройте `Pico.app` через правый клик → **Open** (или **System Settings →
Privacy & Security → Open Anyway**).

Релизы собирает `.github/workflows/release.yml`. Пока он включён только для
Linux x86_64 и Windows x86_64. Каждый push в `main` собирает программу один
раз и обновляет предрелиз `latest`. Если для версии из `Cargo.toml` релиза
ещё нет, те же архивы становятся релизом `v<версия>` с описанием из
`docs/releases/v<версия>.md`, а тег ставится сам. Выпустить новую версию —
значит поднять её в `Cargo.toml`, добавить описание и слить в `main`.
Остальные системы закомментированы в файле, чтобы экономить минуты Actions;
раскомментируйте их, чтобы собирать всё.

## Сборка и запуск

Нужен Rust 1.95 или новее (`rustup`). Для видео и RAW-фото нужен `ffmpeg`
(вместе с `ffprobe`; для звука — `ffplay`) в `PATH` или рядом с программой.
Без него всё остальное работает.

```sh
make release          # или: cargo build --release
make run              # открыть ~/Pictures
./target/release/pico ~/Photos ~/Downloads   # открыть свои папки
```

Готовая программа — один файл `target/release/pico`, его можно скопировать
куда угодно. `make install` ставит её в `~/.cargo/bin`.

**Windows.** `make windows` собирает `pico.exe` прямо на Linux (через zig,
настройка — в комментарии в `Makefile`); на самой Windows работает обычный
`cargo build --release`. Программе нужны только системные DLL Windows 10/11.
Для видео положите `ffmpeg.exe`, `ffprobe.exe`, `ffplay.exe` рядом с `pico.exe`.

**macOS** собирается на Mac (`cargo build --release`) или в GitHub Actions.
`.github/workflows/build.yml` на каждый push проверяет и собирает Linux,
Windows и macOS (Intel и Apple Silicon) и выкладывает программы как артефакты.

Другие команды: `make test` (тесты), `make check` (форматирование, clippy,
тесты), `make testdata` (тестовая библиотека в `testdata/library`, см.
`testdata/README.md`).

## Как пользоваться

### Библиотека

- Слева — раздел **★ Starred Photos** (все отмеченные звёздочкой фото),
  **Albums** (альбомы Picasa), **Timeline** (по годам и месяцам съёмки),
  **Places** (фото с GPS, сгруппированные по месту: ближайший город, иначе
  страна, море или океан, континент; без сети) и **Folders**.
  Папки, указанные при запуске или добавленные через
  **File → Add Folder to Pico…**, запоминаются. В Folder Manager слева дерево диска, справа для выбранной
  папки — **Watch for photos** или **Leave out of Pico**. Правило ближайшей
  папки главнее: можно следить за `~/Pictures`, но выключить
  `~/Pictures/Скриншоты`, а внутри неё снова включить одну папку. Путь можно
  ввести вручную или выбрать системным диалогом (**Browse…**). Изменения
  применяются по **OK**; сами файлы не трогаются.
- **Лоток (Photo Tray)** скрыт, пока его не включит **View → Photo Tray**;
  обычно его работу делают альбомы. Включённый, он внизу: пока он пуст, там
  видно выделение; **Hold** (**Ctrl+H**) кладёт выделенные фото в лоток, и они
  остаются там при переходе между папками. Кнопки **Slideshow**, **Export…**,
  **Make a Collage…**, **Make a Movie…** работают с лотком (или с выделением,
  если лоток пуст); **Unhold** убирает фото из лотка, **Clear** очищает его.
  Слева появляется раздел **Photo Tray**. Файлы при этом никуда не перемещаются.
- Размер миниатюр — **View → Thumbnail size** или **Ctrl+колесо** над фото
  (щипок на тачпаде); **Ctrl+1** / **Ctrl+2** — маленькие и обычные.
- Колесо прокручивает миниатюры «с весом»: они немного катятся по инерции и
  пружинят у верха и низа (выключается в **Tools → Options… → Animations**).
- Выделять можно рамкой: протяните мышью прямоугольник по миниатюрам (с
  **Ctrl** — добавить к выделенному). У края окна сетка прокручивается сама.
- **Перетаскивание.** Миниатюры (выделенные — все сразу) можно бросить на
  папку слева — Pico спросит и перенесёт файлы вместе с подписями, звёздочками,
  правками и сохранённым оригиналом; на альбом — добавить в альбом; на лоток (если
  он включён) — положить в лоток. Папки (и файлы — по их папке) из файлового менеджера можно
  бросить прямо в окно Pico, они добавятся в библиотеку.
- Правый щелчок по миниатюре — меню: звёздочка, поворот, альбом, скрыть,
  экспорт, показать на диске, переименовать, копировать путь, в корзину. Если
  фото не было выделено, меню работает только с ним; иначе — со всем выделенным.
  Правый щелчок по папке слева — слайд-шоу, показать на диске, копировать путь,
  пересканировать, убрать из Pico.
- Разделы слева (**Albums**, **Folders**, **Timeline**, **Places**)
  сворачиваются. Кнопка **…** у **Folders**:
  плоский список или дерево (папки там, где они лежат на диске), сортировка по
  имени, дате (новые сверху, по годам), недавним изменениям или размеру.
- Папки показаны справа одной лентой, как в Picasa: у каждой заголовок с
  названием, числом фото, месяцами съёмки и описанием. Щелчок по папке слева
  прокручивает ленту к ней, а при прокрутке подсвечивается папка вверху.
  Стрелки, просмотр и слайд-шоу работают в пределах одной папки. Так же
  друг за другом идут альбомы, месяцы **Timeline** и **Places**; щелчок по фото
  соседнего раздела делает текущим его.
- Справа — миниатюры. Двойной клик или **Enter** открывает фото; двойной клик
  по открытому фото (или **Esc**) возвращает в библиотеку.
- Над открытым фото — лента соседних снимков; щелчок по миниатюре открывает
  её. Ленту можно убрать: **View → Filmstrip**. Панель под фото в узком окне
  переносится на несколько строк.
- Колесо мыши над фото листает снимки, **Ctrl+колесо** (или щипок на тачпаде)
  меняет масштаб вокруг указателя. Внизу — **Fit** (вписать), **1:1** и ползунок
  до 800%; увеличенное фото двигается мышью. При увеличении большого снимка Pico
  подгружает его в полном разрешении, так что 1:1 показывает настоящие пиксели.
- Над фото — строка о нём: имя, дата съёмки (или дата файла, если камера её
  не записала), размер в пикселях (после кадрирования — и исходный) и размер
  файла; у видео — размер кадра и длительность.
- **Original** внизу (или клавиша **\\**): пока кнопка зажата, видно фото без
  правок — удобно сравнивать до и после.
- **Undo** (**Ctrl+Z**) снимает последнюю правку, **Redo** (**Ctrl+Y** или
  **Ctrl+Shift+Z**) возвращает её. После **Undo All Edits** Redo возвращает
  правки по одной. Новая правка очищает историю Redo.
- **Home/End** — первое и последнее фото. **F11** (или кнопка **⛶**) — полный
  экран: только фото, без меню и панелей; стрелки, колесо и масштаб работают,
  **Esc** или **F11** — выход.
- **Поиск** (поле справа сверху, **Ctrl+F**) ищет по всей библиотеке: имена
  файлов и папок, подписи, ключевые слова.
- Строка состояния внизу справа: имя, дата съёмки и размер фото под курсором
  (или выделенного), а для нескольких — сколько выделено и сколько они весят.
  Пока Pico ищет фото, там же видно, сколько уже найдено.
- Значки в углу миниатюры: **✏** — у фото есть правки, **📍** — известно, где
  оно снято (то же написано во всплывающей подсказке).
- Кнопка **★** рядом с поиском показывает только отмеченные фото, **▶** — только
  видео.
- **View**: размер миниатюр, подписи под ними (имя файла, подпись, теги),
  сортировка (по имени, дате съёмки, размеру, в обратном порядке), показ
  скрытых фото, лоток, слайд-шоу.
- **Alt+Enter** (или **View → Properties and Tags**) открывает справа панель
  с гистограммой фото (красный, зелёный, синий, с правками; одна и та же в
  библиотеке и просмотре), свойствами (размер, разрешение, камера, выдержка,
  ISO, GPS…) и тегами. Ниже — все метаданные файла по разделам (какие открыты, а какие
  свёрнуты, Pico помнит между запусками): все поля EXIF (служебные и
  двоичные — в hex), XMP, IPTC, ICC-профиль, заголовки JPEG, PNG и WebP, теги
  видео и заметки производителя камеры (MakerNote: Canon, Nikon, Olympus,
  Fujifilm, Sony, Casio, Apple, DJI), расшифрованные, где известно их значение.
  Если поля с одним смыслом расходятся (автор, название, описание, права,
  ключевые слова, даты, программа, рейтинг, объектив — в EXIF, XMP, IPTC и PNG;
  копии тегов EXIF в XMP; настройки съёмки, серийные номера, владелец и часы
  камеры в заметках производителя против EXIF и XMP), у каждого из них значок
  «!», а подсказка показывает все значения. Если редактор переложил заметки
  производителя, не поправив их, это тоже видно. По таким следам
  отредактированный файл отличается от снятого камерой. Координаты в строке **GPS** собираются из EXIF, XMP и тегов
  видео и служат ссылкой: открывают это место на OpenStreetMap в браузере;
  если источники расходятся, у них тоже значок «!». Значок **📋 Copy** справа от заголовка копирует
  всё это таблицей (TSV) для вставки в электронную таблицу. **Ctrl+K** сразу
  ставит курсор в поле тега: тег добавляется всем выделенным фото, кнопка с
  крестиком убирает его.

### Альбомы

Альбом — виртуальная подборка фото из любых папок, как в Picasa: кто в каком
альбоме, записано в `.picasa.ini` папок, а сам альбом (название и порядок
фото) — в файле `.pal`, как у Picasa. **Ctrl+N** или **Picture → Add to Album →
New Album…** создаёт альбом из выделенных фото, **Add to Album → имя**
добавляет в существующий, **Remove from Album** или **Delete** (когда альбом
открыт) убирает из альбома, не трогая файл. Фото в альбоме можно расставить
перетаскиванием — сортировка переключится на **View → Sort → Custom Order**.
Фото из папок, которых нет в Pico, показываются чёрными плитками с кнопкой
**Add Folder**. Правый щелчок по альбому слева — **Rename Album…** и **Delete
Album…** (фото остаются на месте).

Выделение: клик — одно фото, **Ctrl+клик** — добавить/убрать, **Shift+клик** —
диапазон, **Ctrl+A / Ctrl+I / Ctrl+D** — выделить всё / инвертировать /
снять. Команды меню **Picture** и **File** работают со всеми выделенными фото.

### Просмотр и правка фото

Внизу — панель: назад в библиотеку, **Edit**, слайд-шоу, листание, звёздочка,
поворот и поле подписи (сохраняется по Enter).

Кнопка **Edit** открывает панель правки:

- **Basic Fixes**: Crop (обрезка рамкой, с готовыми пропорциями), Straighten
  (выравнивание горизонта), I'm Feeling Lucky, Auto Contrast, Auto Color.
- **Tuning**: осветление, светлые, тени, цветовая температура.
- **Effects**: эффекты Picasa (резкость, сепия, Ч/Б, утепление, зерно,
  тонирование, насыщенность, мягкий фокус, свечение, Ч/Б с фильтром, фокусное
  Ч/Б, градиентное тонирование).
- **Creative Kit**: эффекты Picnik (HDR-ish, Lomo, Holga, виньетка, рамки,
  Polaroid, Pencil Sketch, Duo-Tone и другие).

У эффектов с настройками открывается панель с ползунками; центр эффекта
ставится кликом по фото. **Enter** — применить, **Esc** — отменить.
**Undo** убирает последнюю правку, **Undo All Edits** — все.

Правки хранятся в `.picasa.ini`, сам файл не меняется. Чтобы записать их в
файл, есть **File → Save** (оригинал сохраняется в `.picasaoriginals`,
вернуть — **File → Revert**) или **Save a Copy** (рядом появится `имя-1.jpg`).

### Видео

Видео открываются так же, как фото. **/** или **Space** — играть/пауза
(или щелчок по картинке), **,** и **.** — назад/вперёд на 5 секунд, ползунок —
перемотка, **Mute** — без звука. **Save Frame as Photo** в нижней панели
сохраняет текущий кадр рядом с видео. В слайд-шоу видео проигрывается целиком.

### Фильм из фото

**Create → Movie…** делает MP4 из выделенных фото (с правками): 720p или
1080p, время показа каждого фото, плавные переходы, музыка по желанию.

### Коллаж

**Create → Picture Collage…** собирает выделенные фото (или все показанные)
на одном листе. Виды: **Mosaic** (фото встык, заполняют лист), **Frame
Mosaic** (одно фото крупно в центре, остальные рамкой), **Grid** (ровная
сетка), **Contact Sheet** (миниатюры с именами и заголовком), **Multiple
Exposure** (фото наложены друг на друга). Настраиваются формат листа, фон
(цвет или одно из фото), рамки (белая или «Instant» с подписью), тени и
отступы; **Shuffle Pictures** перемешивает порядок. Внизу — список фото:
убрать, сделать фоном или центром. **Create Collage** сохраняет JPG
(3000 px по ширине) рядом с первым фото и кладёт его в альбом «Collages»;
**Desktop Background** ещё и ставит его обоями (GNOME).

### Слайд-шоу

**Ctrl+4** или **View → Slideshow** — на весь экран. **Space** — пауза,
стрелки — листать, **−/+** — время показа, **Esc** — выход.

### Файлы

- **Export Picture to Folder…** (**Ctrl+Shift+S**) — сохраняет копии с правками
  в выбранную папку, с уменьшением размера и выбором качества JPEG.
- **Rename…** (**F2**), **Locate on Disk** (**Ctrl+Enter**), **Open in Editor**
  (**Ctrl+Shift+O**), **Move to Trash…** (**Delete**; корзина Linux, Windows и macOS).
- **Tools → Show Duplicate Files** находит одинаковые файлы во всей библиотеке.
- **Tools → Options…** — тема, анимации, язык, размер и очистка кэша
  миниатюр, найден ли ffmpeg. Изменения сохраняются сразу.

## Оформление и язык

**Tools → Options… → Look**: тема как в системе (по умолчанию), тёмная или
светлая. «Как в системе» на Linux берётся из настроек рабочего стола (портал
XDG: GNOME, KDE и другие) и меняется сразу, без перезапуска. Фото в просмотре и
слайд-шоу всегда на тёмном фоне. **Animations** включает и выключает
летящую звёздочку и прокрутку «с весом».

**Language**: как в системе (по умолчанию), английский или русский; меняется
сразу. Переводы — файлы gettext `.po` в `crates/pico/po`; как добавить язык,
написано в `crates/pico/po/README.md`.

## Где что хранится

- `.picasa.ini` в каждой папке — звёздочки, подписи, правки (совместимо с Picasa).
- `.picasaoriginals/` — оригиналы фото, сохранённых через **Save**.
- `~/.config/pico/watched_folders.txt` и `excluded_folders.txt` — папки
  библиотеки и исключённые из неё.
- `~/.config/pico/settings.txt` — что Pico помнит между запусками: размер
  миниатюр, подписи, сортировку, ленту, лоток, вид списка папок, панель
  свойств, тему, язык, анимации, размер окна, ширину левой и правой панелей, какие разделы слева и в панели
  свойств открыты, и последнюю открытую папку (строки `ключ=значение`, можно
  править руками; записываются через секунду после изменения и при закрытии).
- `~/.config/pico/<токен>.pal` — альбомы в формате Picasa: название, описание,
  дата и фото в порядке альбома.
- `~/.cache/pico/thumbs/` — кэш миниатюр, можно удалять.

## Для разработчиков

- `crates/pico-core` — всё без интерфейса: `.picasa.ini` (`ini`, `meta`), коллажи (`collage`),
  стек правок (`filters`, `rect64`), эффекты (`adjust`, `effects`, `ops`,
  `render`), файлы (`media`, `library`, `export`, `fileops`), метаданные (`exif`,
  `exif_tags`, `maker_notes`, `maker_tags`, `xmp`, `metadata` и `agree` — поля,
  которые должны совпадать), альбомы (`album_file`),
  миниатюры, видео и фильмы (`thumbnail`, `video`, `movie`), настройки (`config`).
- `crates/pico` — приложение egui: библиотека (`app`, `grid`), коллажи (`collage_view`), свойства и
  теги (`info`), просмотр и правка (`viewer`, `tools`), видео (`player`), слайд-шоу (`slideshow`),
  переводы (`i18n`, тексты в `po/`), UI-тесты без окна (`tests`, скриншоты в `target/ui-shots/`).
- `docs/` — заметки проекта, описания релизов
  (`releases/`) и как обновлять редко меняющиеся
  данные — места, теги EXIF, заметки производителей, лицензии — и какие поля метаданных должны
  совпадать (`data-updates.md`).

Эффекты Creative Kit следуют рецептам Picnik (Google, Apache License 2.0).
Названия мест — из [GeoNames](https://www.geonames.org/) (`cities1000`,
CC BY 4.0) и [Natural Earth](https://www.naturalearthdata.com/) (страны, моря,
континенты; общественное достояние). Они упакованы в
`crates/pico-core/data/places.bin` скриптом `crates/pico-core/data/make_places.py`
(`make places`).
Метаданные в панели свойств читаются по описаниям форматов:

- EXIF — стандарт [CIPA DC-008 (Exif 3.0)](https://www.cipa.jp/e/std/std-sec.html);
  названия и типы тегов основного каталога, EXIF, DNG и Interoperability — по
  [справочнику exiv2](https://exiv2.org/tags.html) (`crates/pico-core/src/exif_tags.rs`,
  `make exif-tags`),
  GPS-теги и значения их полей — по [ExifTool](https://exiftool.org/TagNames/GPS.html),
  расшифровка кодов (Exposure Program, Metering Mode, Flash…) — по
  [таблице EXIF ExifTool](https://exiftool.org/TagNames/EXIF.html).
- XMP — [Adobe XMP Specification](https://github.com/adobe/xmp-docs) (части 1–3) и
  [теги XMP в ExifTool](https://exiftool.org/TagNames/XMP.html); свойства `exif:` и
  `tiff:` расшифровываются как одноимённые теги EXIF.
- IPTC — [IPTC-IIM 4.2](https://www.iptc.org/std/IIM/4.2/specification/IIMV4.2.pdf)
  (запись 2), в JPEG — внутри блока Photoshop (ресурс 0x0404).
- ICC-профиль — [ICC.1:2022](https://www.color.org/specification/ICC.1-2022-05.pdf).
- PNG — [спецификация W3C](https://www.w3.org/TR/png-3/) (`IHDR`, `tIME`, `pHYs`,
  `gAMA`, `sRGB`, `iCCP`, текстовые блоки, `eXIf`) и «Raw profile type» ImageMagick.
- WebP — [описание контейнера RIFF](https://developers.google.com/speed/webp/docs/riff_container).
- Видео — вывод [ffprobe](https://ffmpeg.org/ffprobe.html).
- HEIC, HEIF и AVIF — EXIF находится по блокам элементов
  [ISO/IEC 23008-12](https://www.iso.org/standard/83650.html).
- Заметки производителей камер (MakerNote) — названия записей и значения из
  таблиц [ExifRead](https://github.com/ianare/exif-py) (BSD-3-Clause;
  `crates/pico-core/src/maker_tags.rs`, `make maker-tags`), расчёты — по
  [таблицам ExifTool](https://exiftool.org/TagNames/). Сказанное в заметках
  сверяется с EXIF и XMP, и расходящиеся поля получают значок «!».

Все сторонние пакеты и тексты их лицензий видны в **Help → About**; список
лежит в `crates/pico/assets/licenses.txt` и обновляется командой
`make licenses` после смены зависимостей.
