# Getting help

- **How do I…?** Look in the [README](README.md) first, then ask in
  [Discussions](https://github.com/miamibc/picco/discussions).
- **Something is broken?** Open an [issue](https://github.com/miamibc/picco/issues/new/choose)
  with your system, Picco's version (Help → About) and the steps.
- **A security problem?** See [SECURITY.md](SECURITY.md) first: the issue
  should not carry the details.
