# Pico! - my refreshing update to very good old software

You probably know about Picasa. Yes i'm using it all this time. With WINE and dances around the problematic dependencies in Linux. Used it because no good enough replacement, lots of galleries created with this application and idea i like in this software - to keep photos untouched, but add filters and export them with nice filenames, format, size and photo quality.

Suddenly, this application is [not supported anymore](https://sites.google.com/site/picasaresources/picasa/update-picasa-to-latest-version). 

Gladly it's free. 

Suddenly, not open-source. 

Gladly we can build open-source version from scratch.

After small help of AI we can build full-featured open-source version of this application for your lovely OS with only developer's tools and source code. Or you can download built version from [Releases](https://github.com/miamibc/pico/releases) page. For now there are only versions for Windows and Linux made for x86_64 architecture. But Pico can be compiled also for MAC and other ARM processors, feel free to help me in this.

I'm waiting for other developers to be involved. You can help me in creating feature requests in [discussions](https://github.com/miamibc/pico/discussions), adding your [ideas](https://github.com/miamibc/pico/discussions/categories/ideas), leave your votes in [polls](https://github.com/miamibc/pico/discussions/categories/polls), report [bugs](https://github.com/miamibc/pico/issues) and push your merge requests of course. If you prefer to use software silently - no problem, i wish you the best. But if you want to give me few bucks for this, you can do this soon too. 

Thanks anyway!
