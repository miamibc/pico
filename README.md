# Pico

Небольшой локальный органайзер фотографий в духе Picasa 3. Написан на Rust
и egui, работает на Linux, Windows и macOS.

Pico читает и пишет файлы `.picasa.ini`, которые Picasa оставляла в папках с
фотографиями. Звёздочки, подписи, ключевые слова, повороты и правки, сделанные
в Picasa, видны в Pico и наоборот. Оригиналы фотографий Pico не меняет, пока
вы явно не нажмёте **Save**. В интернет ничего не отправляет.

## Готовые сборки

На странице релизов GitHub лежат архивы под все системы. Процессоры Intel и
AMD берут одни и те же сборки `x86_64` (64 бита) или `x86` (32 бита).

| Система | 64 бита | 32 бита | ARM |
|---|---|---|---|
| Linux (glibc 2.28+, 2019 г. и новее) | `pico-linux-x86_64` | `pico-linux-x86` | `pico-linux-arm64`, `pico-linux-armv7` (32-бит, Raspberry Pi) |
| Windows 10/11 | `pico-windows-x86_64` | `pico-windows-x86` | `pico-windows-arm64` |
| macOS 11+ | `pico-macos` — одна программа для Apple Silicon и Intel | — | — |

Сборка для macOS не подписана сертификатом Apple: при первом запуске
откройте `Pico.app` через правый клик → **Open** (или **System Settings →
Privacy & Security → Open Anyway**).

Релизы собирает `.github/workflows/release.yml`. Пока он включён только для
Linux x86_64: каждый push в `main` обновляет релиз `latest`. Остальные системы
и релизы по тегам `v*` закомментированы в файле, чтобы экономить минуты
Actions; раскомментируйте их, чтобы собирать всё.

## Сборка и запуск

Нужен Rust 1.95 или новее (`rustup`). Для видео и RAW-фото нужен `ffmpeg`
(вместе с `ffprobe`; для звука — `ffplay`) в `PATH` или рядом с программой.
Без него всё остальное работает.

```sh
make release          # или: cargo build --release
make run              # открыть ~/Pictures
./target/release/pico ~/Photos ~/Downloads   # открыть свои папки
```

Готовая программа — один файл `target/release/pico`, его можно скопировать
куда угодно. `make install` ставит её в `~/.cargo/bin`.

**Windows.** `make windows` собирает `pico.exe` прямо на Linux (через zig,
настройка — в комментарии в `Makefile`); на самой Windows работает обычный
`cargo build --release`. Программе нужны только системные DLL Windows 10/11.
Для видео положите `ffmpeg.exe`, `ffprobe.exe`, `ffplay.exe` рядом с `pico.exe`.

**macOS** собирается на Mac (`cargo build --release`) или в GitHub Actions.
`.github/workflows/build.yml` на каждый push проверяет и собирает Linux,
Windows и macOS (Intel и Apple Silicon) и выкладывает программы как артефакты.

Другие команды: `make test` (тесты), `make check` (форматирование, clippy,
тесты), `make testdata` (тестовая библиотека в `testdata/library`, см.
`testdata/README.md`).

## Как пользоваться

### Библиотека

- Слева — раздел **★ Starred Photos** (все отмеченные звёздочкой фото),
  **Albums** (альбомы Picasa), **Timeline** (по годам и месяцам съёмки),
  **Places** (фото с GPS, сгруппированные по местности) и **Folders**.
  Папки, указанные при запуске или добавленные через
  **File → Add Folder to Pico…** (он же **Tools → Folder Manager…**),
  запоминаются. В Folder Manager слева дерево диска, справа для выбранной
  папки — **Watch for photos** или **Leave out of Pico**. Правило ближайшей
  папки главнее: можно следить за `~/Pictures`, но выключить
  `~/Pictures/Скриншоты`, а внутри неё снова включить одну папку. Путь можно
  ввести вручную или выбрать системным диалогом (**Browse…**). Изменения
  применяются по **OK**; сами файлы не трогаются.
- **Лоток (Photo Tray)** внизу: пока он пуст, там видно выделение; **Hold**
  (**Ctrl+H**) кладёт выделенные фото в лоток, и они остаются там при переходе
  между папками. Кнопки **Slideshow**, **Export…**, **Make a Collage…**, **Make a Movie…**
  работают с лотком (или с выделением, если лоток пуст); **Remove** убирает
  выделенные из лотка, **Clear** очищает его. Слева появляется раздел
  **Photo Tray**. Файлы при этом никуда не перемещаются.
- Размер миниатюр — ползунок внизу справа или **Ctrl+колесо** над фото
  (щипок на тачпаде); **Ctrl+1** / **Ctrl+2** — маленькие и обычные.
- Выделять можно рамкой: протяните мышью прямоугольник по миниатюрам (с
  **Ctrl** — добавить к выделенному). У края окна сетка прокручивается сама.
- **Перетаскивание.** Миниатюры (выделенные — все сразу) можно бросить на
  папку слева — Pico спросит и перенесёт файлы вместе с подписями, звёздочками,
  правками и сохранённым оригиналом; на альбом — добавить в альбом; на лоток —
  положить в лоток. Папки (и файлы — по их папке) из файлового менеджера можно
  бросить прямо в окно Pico, они добавятся в библиотеку.
- Правый щелчок по миниатюре — меню: звёздочка, поворот, альбом, скрыть,
  экспорт, показать на диске, переименовать, копировать путь, в корзину. Если
  фото не было выделено, меню работает только с ним; иначе — со всем выделенным.
  Правый щелчок по папке слева — слайд-шоу, показать на диске, копировать путь,
  пересканировать, убрать из Pico.
- Справа — миниатюры. Двойной клик или **Enter** открывает фото; двойной клик
  по открытому фото (или **Esc**) возвращает в библиотеку.
- Над открытым фото — лента соседних снимков; щелчок по миниатюре открывает
  её. Ленту можно убрать: **View → Filmstrip**.
- Колесо мыши над фото листает снимки, **Ctrl+колесо** (или щипок на тачпаде)
  меняет масштаб вокруг указателя. Внизу — **Fit** (вписать), **1:1** и ползунок
  до 800%; увеличенное фото двигается мышью. При увеличении большого снимка Pico
  подгружает его в полном разрешении, так что 1:1 показывает настоящие пиксели.
- Над фото — строка о нём: имя, дата съёмки (или дата файла, если камера её
  не записала), размер в пикселях (после кадрирования — и исходный) и размер
  файла; у видео — размер кадра и длительность.
- **Original** внизу (или клавиша **\\**): пока кнопка зажата, видно фото без
  правок — удобно сравнивать до и после.
- Внизу панели **Edit** — гистограмма (красный, зелёный, синий; меняется вместе
  с правками) и данные камеры: модель, выдержка, диафрагма, ISO, фокусное
  расстояние.
- **Undo** (**Ctrl+Z**) снимает последнюю правку, **Redo** (**Ctrl+Y** или
  **Ctrl+Shift+Z**) возвращает её. После **Undo All Edits** Redo возвращает
  правки по одной. Новая правка очищает историю Redo.
- **Home/End** — первое и последнее фото. **F11** (или кнопка **⛶**) — полный
  экран: только фото, без меню и панелей; стрелки, колесо и масштаб работают,
  **Esc** или **F11** — выход.
- **Поиск** (поле справа сверху, **Ctrl+F**) ищет по всей библиотеке: имена
  файлов и папок, подписи, ключевые слова.
- Кнопка **★** рядом с поиском показывает только отмеченные фото.
- **View**: размер миниатюр, подписи под ними (имя файла, подпись, теги),
  сортировка (по имени, дате съёмки, размеру, в обратном порядке), показ
  скрытых фото, слайд-шоу.
- **Alt+Enter** (или **View → Properties and Tags**) открывает справа панель
  со свойствами фото (размер, разрешение, камера, выдержка, ISO, GPS…) и
  тегами. **Ctrl+K** сразу ставит курсор в поле тега: тег добавляется всем
  выделенным фото, кнопка с крестиком убирает его. Для фото с GPS есть кнопка
  **Show on OpenStreetMap** (открывает карту в браузере).

### Альбомы

Альбом — виртуальная подборка фото из любых папок, как в Picasa (хранится в
тех же `.picasa.ini`). **Ctrl+N** или **Picture → Add to Album → New Album…**
создаёт альбом из выделенных фото, **Add to Album → имя** добавляет в
существующий, **Remove from Album** (когда альбом открыт) убирает из него.

Выделение: клик — одно фото, **Ctrl+клик** — добавить/убрать, **Shift+клик** —
диапазон, **Ctrl+A / Ctrl+I / Ctrl+D** — выделить всё / инвертировать /
снять. Команды меню **Picture** и **File** работают со всеми выделенными фото.

### Просмотр и правка фото

Внизу — панель: назад в библиотеку, **Edit**, слайд-шоу, листание, звёздочка,
поворот и поле подписи (сохраняется по Enter).

Кнопка **Edit** открывает панель правки:

- **Basic Fixes**: Crop (обрезка рамкой, с готовыми пропорциями), Straighten
  (выравнивание горизонта), I'm Feeling Lucky, Auto Contrast, Auto Color.
- **Tuning**: осветление, светлые, тени, цветовая температура.
- **Effects**: эффекты Picasa (резкость, сепия, Ч/Б, утепление, зерно,
  тонирование, насыщенность, мягкий фокус, свечение, Ч/Б с фильтром, фокусное
  Ч/Б, градиентное тонирование).
- **Creative Kit**: эффекты Picnik (HDR-ish, Lomo, Holga, виньетка, рамки,
  Polaroid, Pencil Sketch, Duo-Tone и другие).

У эффектов с настройками открывается панель с ползунками; центр эффекта
ставится кликом по фото. **Enter** — применить, **Esc** — отменить.
**Undo** убирает последнюю правку, **Undo All Edits** — все.

Правки хранятся в `.picasa.ini`, сам файл не меняется. Чтобы записать их в
файл, есть **File → Save** (оригинал сохраняется в `.picasaoriginals`,
вернуть — **File → Revert**) или **Save a Copy** (рядом появится `имя-1.jpg`).

### Видео

Видео открываются так же, как фото. **/** или **Space** — играть/пауза,
**,** и **.** — назад/вперёд на 5 секунд, ползунок — перемотка. **Set Start /
Set End** обрезают воспроизведение (файл не меняется), **Save Frame as Photo**
сохраняет текущий кадр рядом с видео.

### Фильм из фото

**Create → Movie…** делает MP4 из выделенных фото (с правками): 720p или
1080p, время показа каждого фото, плавные переходы, музыка по желанию.

### Коллаж

**Create → Picture Collage…** собирает выделенные фото (или все показанные)
на одном листе. Виды: **Mosaic** (фото встык, заполняют лист), **Frame
Mosaic** (одно фото крупно в центре, остальные рамкой), **Grid** (ровная
сетка), **Contact Sheet** (миниатюры с именами и заголовком), **Multiple
Exposure** (фото наложены друг на друга). Настраиваются формат листа, фон
(цвет или одно из фото), рамки (белая или «Instant» с подписью), тени и
отступы; **Shuffle Pictures** перемешивает порядок. Внизу — список фото:
убрать, сделать фоном или центром. **Create Collage** сохраняет JPG
(3000 px по ширине) рядом с первым фото и кладёт его в альбом «Collages»;
**Desktop Background** ещё и ставит его обоями (GNOME).

### Слайд-шоу

**Ctrl+4** или **View → Slideshow** — на весь экран. **Space** — пауза,
стрелки — листать, **−/+** — время показа, **Esc** — выход.

### Файлы

- **Export Picture to Folder…** (**Ctrl+Shift+S**) — сохраняет копии с правками
  в выбранную папку, с уменьшением размера и выбором качества JPEG.
- **Rename…** (**F2**), **Locate on Disk** (**Ctrl+Enter**), **Open in Editor**
  (**Ctrl+Shift+O**), **Move to Trash…** (**Delete**; корзина Linux, Windows и macOS).
- **Tools → Show Duplicate Files** находит одинаковые файлы во всей библиотеке.
- **Tools → Options…** — размер и очистка кэша миниатюр, найден ли ffmpeg.

## Горячие клавиши

| Где | Клавиши | Действие |
|---|---|---|
| Библиотека | стрелки, Enter | выбор, открыть |
| Библиотека | S | звёздочка |
| Везде | Ctrl+R / Ctrl+Shift+R | повернуть по / против часовой |
| Библиотека | Ctrl+Shift+E / Ctrl+Shift+B | I'm Feeling Lucky / Ч/Б |
| Библиотека | Ctrl+1 / Ctrl+2 | маленькие / обычные миниатюры |
| Библиотека | Ctrl+F | поиск |
| Библиотека | Ctrl+N | новый альбом из выделенных |
| Везде | Alt+Enter / Ctrl+K | свойства и теги / добавить тег |
| Везде | Ctrl+4 | слайд-шоу |
| Фото | ← → , Esc, S | листать, назад, звёздочка |

## Где что хранится

- `.picasa.ini` в каждой папке — звёздочки, подписи, правки (совместимо с Picasa).
- `.picasaoriginals/` — оригиналы фото, сохранённых через **Save**.
- `~/.config/pico/watched_folders.txt` и `excluded_folders.txt` — папки
  библиотеки и исключённые из неё.
- `~/.cache/pico/thumbs/` — кэш миниатюр, можно удалять.

## Для разработчиков

- `crates/pico-core` — всё без интерфейса: `.picasa.ini` (`ini`, `meta`), коллажи (`collage`),
  стек правок (`filters`, `rect64`), эффекты (`adjust`, `effects`, `ops`,
  `render`), файлы (`media`, `library`, `export`, `fileops`, `exif`),
  миниатюры, видео и фильмы (`thumbnail`, `video`, `movie`), настройки (`config`).
- `crates/pico` — приложение egui: библиотека (`app`, `grid`), коллажи (`collage_view`), свойства и
  теги (`info`), просмотр и правка (`viewer`, `tools`), видео (`player`), слайд-шоу (`slideshow`),
  UI-тесты без окна (`tests`, скриншоты в `target/ui-shots/`).
- `docs/` — заметки проекта, список заданий (`tasks.md`) и разбор форматов Picasa 3.
- `research/` — материалы реверс-инжиниринга (не в git).
