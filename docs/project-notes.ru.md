# Pico — заметки по проекту

[English](project-notes.md) · **Русский**

Pico — переписанный на Rust аналог Google Picasa 3 с небольшими изменениями и
улучшениями. Сборки под Linux, Windows, возможно macOS; минимум зависимостей,
простая сборка и запуск.

## Решения

- **Интерфейс:** egui.
- **Тексты:** пока только английские. Можно добавить немного юмора, чтобы
  отличаться от оригинала. Строки и ресурсы Google не копируем.
- **Метаданные:** поддерживаем файлы `.picasa.ini` (и старые `Picasa.ini`),
  которые Picasa оставляет в каждой папке с фотографиями. Формат —
  `docs/research/picasa3-analysis.md`.
- **Сеть:** сетевых функций пока не делаем, в облако ничего не загружаем.
- **Видео:** читаем и обрабатываем через ffmpeg.
- **Форматы:** поддержать все возможные форматы фото и видео.
