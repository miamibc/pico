## Ветка `my-additions`

Программа уже очень неплоха, вот что можно улучшить. Если что-то из этого сделать нельзя или слишком сложно - сообщай. 

1. [x] Переключение тёмной/светлой темы можно ли делать через какие-нибудь хуки, события или dbus сообщения. Идея сделать так чтобы приложение получило сигнал о том что тема поменялась и применило это изменение - и в Linux и в Windows. Вариант постоянно опрашивать систему мне кажется не очень правильным.
2. [x] Список places в левой части указывает координаты найденные в meta тегах. Можно ли к ним добавить еще и название мест, если они опознались. Поищи подходящие открытые источники, где можно вытаскивать много координат одним запросом, предложи мне эти варианты. Правило "без сети" можно употребить здесь, если мы скачаем координаты всех более-менее известных мест, а также стран, морей, материков и океанов. Поиск мможет найти самое близкое из мест которые имеются в этих списках, руководствуясь гранулярностью объекта. Сначала выбирается город, если не нашло то страна, потом континент или море. Это даст нам возможность детектору мест работать оффлайн.
3. [x] Предложи варианты логотипа приложения. Лого будет вставлено в меню help/about, файл readme.md в репозитории, поэтому делай в векторе
4. [ ] Удали упоминание функции опознавания людей, можно оставить только в todo.md на неопределенное будущее
5. [ ] Мне кажется или кнопки в диалогах (Ok, Cancel и все остальные) очень маленькие. Можно ли в них (и в дизайн всего приложения) добавить немного воздуха. Если нет то скажи нет, переделывать всё приложение из-за этого не стоит.
6. [ ] Диалог прогресса при создании видео из выбранных фотографий, экспорте и другим операциям которые занимают время.
7. [ ] Выделяя фоторафии можно добавить их в трей кнопкой hold, но отсутствует возможность сделать unhold. Давай посмотрим как этот трей работал в референсном приложении.
8. [ ] В оригинале при проставлении звёздочки в режиме просмотра фотографии, играет анимациа - звёздочка летит из кнопки в центр фотграфии. Можно сделать что-то подобное, близкое, где 3d звездочка красиво разворачивается на экране. Под ней есть небольшая тень, чтобы и на светлом и на темном экране её было заметно. Анимацию можно сделать агентом с большим усилием.

## Отложено на будущее

Решение от 2026-10-26: пока не делаем, вернуться позже.

- **Люди** (People). Поиск лиц на фото, имена, альбомы людей. Формат уже
  известен: `faces=rect64(...),<id>` и секция `[Contacts2]` в `.picasa.ini`
  (см. `docs/research/picasa3-analysis.md`); Pico эти данные читает и
  сохраняет, но не показывает и не ищет лица.
- **Печать** (Print, Print Contact Sheet). Раскладка по листам, размеры
  отпечатков, печать через систему.

## Сделано 2026-10-26

- Системный диалог выбора папки (`rfd`: xdg-portal / zenity, Windows, macOS).
- Корзина на Windows (PowerShell, Recycle Bin) и macOS (Finder). Проверено
  только построение команд: запустить здесь нельзя.
- Сборки: Windows `.exe` с Linux (`make windows`, проверено под wine с
  Vulkan), macOS и всё остальное — GitHub Actions.
- Хронология (Timeline) и места (Places, без карты: карта — сетевая функция).
- Фильм из фото (Create → Movie).

## Сделано 2026-10-27

- Коллаж (Create → Picture Collage): Mosaic, Frame Mosaic, Grid, Contact
  Sheet, Multiple Exposure. Вид «Picture Pile» (рассыпанные фото) по решению
  пользователя убран.

- Folder Manager как в Picasa: дерево диска, для папки — следить или
  исключить (ближайшее правило главнее), ввод пути и системный диалог.
- Релизы в GitHub Actions (`release.yml`, по тегу `v*`): Linux x86_64, x86,
  arm64, armv7 (zigbuild, glibc 2.28), Windows x86_64, x86, arm64, macOS
  universal `.app` (без подписи Apple). Linux-сборки проверены локально;
  Windows и macOS проверятся только при первом запуске в Actions.

## Идеи на потом

- Карта для Places без сети (офлайн-подложка) или по явному разрешению.
- Под wine `pico.exe` падает на DirectX 12 (компилятор шейдеров wine), с
  Vulkan работает. На настоящей Windows сборка ещё не проверялась; если
  DirectX 12 подведёт и там (слабые или виртуальные машины), переключаться на
  Vulkan или OpenGL.
